This repository is a small Python-based live wallpaper generator focused on a standalone CLI workflow rather than the full Swift app. The main entrypoints are `script.py` for transcoding/patching a video into a macOS-live-wallpaper-compatible MOV and `apply_wallpaper.py` for localhost-backed registration/application into the macOS wallpaper catalog. The repo also includes sample input videos and a README with standalone usage instructions.
